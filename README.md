## 📌 Overview
VeriStream AI is an end-to-end Machine Learning solution designed to combat the spread of digital misinformation. By leveraging Natural Language Processing (NLP) and a Passive-Aggressive Classifier, the system distinguishes between authentic reporting and fabricated news with high precision.



## 🚀 Key Features
* **Real-time Prediction:** Interactive web interface built with Streamlit.
* **Optimized NLP Pipeline:** Implements TF-IDF vectorization with custom stop-word filtering.
* **High-Performance Modeling:** Uses a Passive-Aggressive Classifier, ideal for large-scale text streams.
* **Explainable Metrics:** Detailed evaluation via Confusion Matrices and F1-Scores.

## 🛠️ Tech Stack
* **Language:** Python 3.11
* **Data Processing:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (TF-IDF, Passive-Aggressive Classifier)
* **Model Serialization:** Pickle
* **Deployment:** Streamlit
